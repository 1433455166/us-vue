# 版本 0.0.4 - 歌词功能开发与播放器优化

**发布日期**: 2026-07-05

## 主要功能

### 1. 歌词同步显示功能
- 实现歌词解析与时间戳同步（支持 [MM:SS] 和 [MM:SS.xxx] 格式）
- 歌词实时高亮显示当前播放行
- 支持歌词自动滚动，当前歌词显示在可视区域内
- 歌词抽屉支持全屏切换
- 支持点击歌词定位到对应播放位置

### 2. 歌词抽屉组件
- 创建独立的歌词抽屉组件 (`LyricsDrawer.vue`)
- 支持迷你播放器控制（播放/暂停）
- 实现3秒防抖机制：用户手动滑动后3秒内不自动滚动
- 播放状态与外部播放器实时同步

### 3. 播放列表抽屉化
- 将播放列表改为抽屉式显示
- 优化移动端交互体验

### 4. 修复的问题
- 修复 Vite 代理路径不匹配问题
- 修复歌词时间戳同步偏差问题
- 修复歌词页面音乐停止及点击无响应问题
- 修复歌词滚动位置过高问题
- 修复播放按钮状态不同步问题
- 修复歌词抽屉播放按钮点击不更新 isPlaying 状态问题
- 修复点击歌词播放时按钮不更新问题

## 使用说明

### 访问路径
- **音乐播放页面**: `/music` (受密码保护)
- **音乐列表页面**: `/musicList` (受密码保护)

### 功能特点
- 点击歌词可跳转播放位置
- 歌词自动滚动，保持当前歌词在可视区域
- 手动滑动歌词后3秒自动恢复定位
- 支持歌词抽屉全屏显示
- 播放状态完全同步

### 歌词文件格式
歌词文件需放置在 `public/mp3/lyrics/` 目录下，支持以下时间戳格式：
- `[00:28] 歌词内容`
- `[00:28.500] 歌词内容`
