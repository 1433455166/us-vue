# 版本 0.0.5 - 音乐库扩展与 UI 优化

**发布日期**: 2026-07-06

## 主要功能

### 1. 音乐库扩展
- 新增 8 首歌曲（偏爱、抽离、后会无期、听妈妈的话、水手、爱情鸟、稻香、小苹果）
- 统一 MP3 文件命名格式（改为英文名称）
- 添加对应歌词文件支持

### 2. UI 优化
- 播放列表抽屉项添加间隔（gap: 10px）
- 音乐列表添加垂直滚动功能
- 优化列表项视觉效果

### 3. 歌词时间校准
- 调整《后会无期》歌词时间戳（减 1.5 秒）
- 优化歌词同步精度
