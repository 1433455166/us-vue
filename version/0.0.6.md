# 版本 0.0.6 - 播放器交互优化与 SVG 组件化

**发布日期**: 2026-08-16

## 主要功能

### 1. 播放器背景与页面联动
- 封面背景仅在歌曲页（主页）显示，滑动到歌词页时背景淡出，歌词页为纯净深色底

### 2. "更多"按钮操作面板
- 新增底部弹层：定时关闭（10/20/30/60 分钟）、倍速播放（0.5x ~ 2x）、收藏
- 打开面板时阻止底部手势滑页，避免误触

### 3. 设置按钮图标修复
- 顶部"更多/设置"按钮三个圆点显式指定 `fill="currentColor"`，修复深色背景下不可见问题

### 4. 歌词滑动动画
- 首页歌词轮播切换改为同屏交叉滚动：旧行上滑淡出的同时新行从下方滑入，无空窗卡顿
- 歌词页用户手动滚动时不再被播放进度抢回位置

### 5. SVG 图标组件化
- 新增 `src/components/svgIcon/` 文件夹
- 抽取使用两次以上的图标为独立小组件：
  - `SvgPlay.vue`（播放三角，2 处使用）
  - `SvgPause.vue`（暂停双条，2 处使用）
  - `SvgClose.vue`（关闭 X，4 处使用，支持实心/细线变体）
  - `SvgChevron.vue`（方向箭头，3 处使用，支持左/右/上/下）
