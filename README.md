# us-vue

这是一个 vue 项目

## 响应式布局

项目采用响应式设计,针对不同设备屏幕尺寸进行了适配优化:

### 断点设置

- **手机端**: `max-width: 767px`
- **平板端**: `768px - 1023px`
- **大屏幕电脑**: `1024px - 1439px`
- **超大屏幕**: `min-width: 1440px`

### 实现代码

```css
/* 手机端 */
@media (max-width: 767px) {
  .card {
    max-width: 100%;
    margin: 0;
  }
}

/* 平板端 */
@media (min-width: 768px) and (max-width: 1023px) {
  .card {
    max-width: 40%;
  }
}

/* 大屏幕电脑 */
@media (min-width: 1024px) and (max-width: 1439px) {
  /* .card { max-width: 22%; } */
}

/* 超大屏幕 */
@media (min-width: 1440px) {
  /* .card { max-width: 18%; } */
}
```

### 说明

- 手机端卡片占满全宽,无边距
- 平板端卡片宽度为40%,可并排显示两个卡片
- 大屏幕和超大屏幕的卡片宽度配置已注释,可根据实际需求启用

## 音乐文件下载

### 资源获取方式

本项目中的音乐资源通过以下工具获取:

#### 1. AixDownloader 插件
- **功能说明**: 网页音乐资源批量下载工具
- **使用场景**: 从在线音乐平台抓取音频文件
- **优势**: 支持多种音乐网站,操作简便,可批量下载

#### 2. Unlock Music (音乐解锁工具)
- **功能说明**: 用于解密部分音乐平台下载的加密格式文件
- **限制说明**: 对于当前主流音乐 App 下载的最新加密格式文件,该工具可能无法完全破解
- **替代方案**: 建议优先使用 AixDownloader 直接从网页获取标准格式音频

### 注意事项
- 下载的音乐文件请确保格式为浏览器支持的通用格式(如 MP3、OGG 等)
- 加密格式(如 .mgg、.ncm 等)需先转换为标准格式后再引入项目
- 请遵守相关平台的使用条款和版权规定,仅用于个人学习和研究
